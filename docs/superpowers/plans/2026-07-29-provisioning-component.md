# DDP Inspector Provisioning Component Implementation Plan (Plan 2 of 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `provisioning/` tree that turns `daniellemccool/ddp-inspector` into a study-blind SRC catalog component: preflight (volume auto-detect + asserts), app install behind SRC-Nginx, and the systemd-driven refresh machinery — with hermetic Tier-1/Tier-2 tests and an operator runbook.

**Architecture:** One Ansible play (`provisioning/deploy-ddp-inspector.yaml`) run locally by SRC-External, three roles (`preflight`, `inspector`, `refresh`). Everything study-specific lives on the auto-detected volume under `<storage_root>/ddp-inspector/`; the component installs software and wiring only. The refresh service is a source-mode-dispatching bash script driven by state files the PHP app writes (Plan 1), executed by systemd path/timer units. Conventions are ported verbatim from `d3i-infra/researchcloud-ddp-transcribe` (single play `vars:`, fully-qualified modules, `| bool` coercion, generated-file headers, actionable `fail_msg`s, extra-vars resolved into differently-named facts, hermetic test harnesses).

**Tech Stack:** Ansible ≥ 9.1 (SRC-External's `remote_ansible_version`), bash, systemd, php-fpm (Ubuntu 24.04 → PHP 8.3), GoCommands `v0.12.2` (ticket auth), rclone `v1.67.0` (WebDAV), jq, yamllint + ansible-lint, docker for Tier-2.

## Global Constraints

- Target OS: Ubuntu 24.04 (SRC-OS image); PHP ≥ 8.1 required by the app (24.04 ships 8.3).
- Reuse-not-rebuild: SRC-Nginx provides TLS + the SRAM `/validate` endpoint — **never install or configure nginx itself**; only ADD `/etc/nginx/app-location-conf.d/ddp-inspector.conf`.
- No Co-Secrets, no study parameters, no interactive parameters. Component params: `inspector_base_path` (default `/inspector`), `storage_path` (placeholder = auto-detect). Both Fixed + Overwritable at the portal.
- A storage volume is REQUIRED — no boot-disk fallback, ever.
- Volume auto-detect: only block-device filesystems (`ext4`, `xfs`) qualify; `fuse.*` (e.g. RD-by-Link rclone mounts) are excluded. `<`-containing `storage_path` counts as unset (S9). Multiple candidates fail loudly (S10).
- Provisioning must be idempotent: Tier-2 second run reports `changed=0`.
- SRC parameter values arrive as extra-vars (outrank `set_fact`): resolve inputs into differently-named facts (`storage_path` → `storage_root`).
- Generated files carry the header `Generated by the ddp-inspector component — do not edit.`
- Preflight `fail_msg`s are operator-facing (may be technical); everything the refresh script writes into `refresh-status.json` is researcher-facing plain language (spec §2/§6).
- The service account for php-fpm and the refresh service is `www-data` (Ubuntu php-fpm default pool user). This keeps the parameter surface free of a username parameter; the on-volume tree is chowned to it. (Conscious adaptation of the spec's "workspace user" wording — recorded in OPERATIONS.md.)
- Pinned shared contracts with Plan 1 (do not alter):
  - Tree: `<storage_root>/ddp-inspector/{config/{instance.json,source.json,flows/…},data/{inbox/,analyses/transcripts/},state/{refresh-requested,refresh-status.json,refresh.log},cache/}`
  - `instance.json`: `{"study_name":string,"source_mode":"yoda"|"rd-link"|"local","local_path":string|null,"cadence":"off"|"daily","default_n":int,"analysis_dirs":{…}?}`
  - `source.json`: `{"mode":"yoda","collection":string,"host":"fsw.data.uu.nl","zone":"nluu10p","ticket":string}` OR `{"mode":"rd-link","webdav_url":string,"share_token":string,"password":string}`
  - `refresh-status.json`: `{"phase":"idle"|"probing"|"pulling"|"extracting"|"done"|"error","started_at":ISO8601|null,"finished_at":ISO8601|null,"donations":int|null,"message":string}`
  - `config.php` keys templated here: `storage_root`, `base_path`, `default_n`, `gocmd_bin`, `rclone_bin`.
  - The app touches `state/refresh-requested`; the refresh service consumes/removes it.

`provisioning/deploy-ddp-inspector.yaml`:

```yaml
---
# Entry playbook for the ddp-inspector SRC catalog component.
# Run by SRC-External on the workspace itself (local connection, stock
# Ansible). Study-blind by design: installs php-fpm + the app (from this
# repo's own clone) behind the SRC-Nginx SRAM gate, plus the systemd
# refresh machinery. ALL study configuration (flow exports, data source,
# tickets/links) happens post-launch in the app's web UI and lives on the
# storage volume — this play carries no secrets and no study identity.
#
# Required workspace shape (asserted by preflight, operator-facing):
#   - SRC-Nginx ran earlier in the item (provides TLS + /validate).
#   - Exactly one storage volume attached (or storage_path set explicitly).
#
# Optional parameters:
#   inspector_base_path  URL prefix the app is served under (must match the
#                        nginx location; default /inspector).
#   storage_path         override for the storage volume mount path. Normally
#                        leave unset/placeholder: preflight auto-detects the
#                        single block-device volume mounted under <home>/data
#                        ('<...>' placeholder counts as unset; fuse mounts
#                        such as Research-Drive-by-Link never qualify).
#
# SRC parameter values arrive as extra-vars and take precedence. Booleans
# may arrive as strings — every consumer coerces with `| bool`.
- name: Provision ddp-inspector workspace
  hosts: 127.0.0.1
  connection: local
  gather_facts: true
  become: true
  vars:
    inspector_base_path: "/inspector"
    inspector_install_dir: "/opt/ddp-inspector"
    # Ubuntu php-fpm default pool user; owns the on-volume tree and runs
    # the refresh service. Deliberately NOT a parameter (study-blind).
    inspector_service_user: "www-data"
    inspector_service_group: "www-data"
    # GoCommands release (static binary; ticket-capable). Pinned — bump only
    # against a verified gocmd/iRODS combo (transcribe repo precedent).
    gocmd_version: "v0.12.2"
    gocmd_release_base: "https://github.com/cyverse/gocommands/releases/download"
    gocmd_url: "{{ gocmd_release_base }}/{{ gocmd_version }}/gocmd-{{ gocmd_version }}-linux-amd64.tar.gz"
    # rclone release (static binary; WebDAV client for RD share links).
    rclone_version: "v1.67.0"
    rclone_url: "https://downloads.rclone.org/{{ rclone_version }}/rclone-{{ rclone_version }}-linux-amd64.zip"
    # Upload ceiling for flow-export zips (nginx + PHP must agree).
    inspector_upload_max: "64m"
  roles:
    - role: preflight
    - role: inspector
    - role: refresh
```

- [ ] **Step 1: Write the failing test harness** (adapted from the transcribe repo's `test-preflight-autodetect.sh`; the new cases are 2, 5, 6)

`provisioning/scripts/test-preflight-autodetect.sh`:

```bash
#!/usr/bin/env bash
# test-preflight-autodetect.sh — hermetic tests for preflight's storage-volume
# auto-detection (no SRC needed). Runs the real preflight role via a scratch
# play, injecting fake mount tables (storage_mounts_source, WITH fstype) and a
# temp data root (storage_data_root). Contract under test: the storage_path
# INPUT (an SRC extra-var, which set_fact cannot override) resolves into the
# storage_root FACT; exactly one BLOCK-DEVICE (ext4/xfs) mount qualifies;
# fuse.* mounts (Research-Drive-by-Link) never qualify; no volume = loud fail.
set -uo pipefail   # no -e: failures are counted and reported

HERE="$(cd "$(dirname "$0")" && pwd)"
PROV="$(dirname "$HERE")"
PLAYBOOK="${PROV}/.venv/bin/ansible-playbook"
[ -x "${PLAYBOOK}" ] || { echo "missing ${PLAYBOOK} — set up provisioning/.venv first" >&2; exit 2; }

TMP="$(mktemp -d)"
trap 'rm -rf "${TMP}"' EXIT

FAIL=0
check() { local desc="$1"; shift; if "$@" >/dev/null 2>&1; then echo "ok: ${desc}"; else echo "FAIL: ${desc}"; FAIL=$((FAIL+1)); fi; }

DATA="${TMP}/data"
NGINXDIR="${TMP}/nginx-conf.d"; mkdir -p "${NGINXDIR}"

cat > "${TMP}/scratch.yaml" <<'PLAY'
---
- name: Preflight auto-detect scratch harness
  hosts: 127.0.0.1
  connection: local
  gather_facts: false
  vars:
    inspector_base_path: "/inspector"
    inspector_install_dir: "/opt/ddp-inspector"
    inspector_service_user: "www-data"
    inspector_service_group: "www-data"
    # Skip the php/nginx environment asserts' real-system checks are fed
    # by the harness (nginx_confdir points at a temp dir; php check is
    # satisfied by the host having php or by preflight_skip_php below).
  roles:
    - role: preflight
  tasks:
    - name: Report resolved facts
      ansible.builtin.debug:
        msg: "RESOLVED storage_root=[{{ storage_root | default('') }}] inspector_root=[{{ inspector_root | default('') }}]"
PLAY

mounts() { # mounts <dir:fstype ...> -> -e JSON dict with fstype-carrying entries
  local out first=1 spec d t
  out='{"storage_mounts_source": ['
  for spec in "$@"; do
    d="${spec%%:*}"; t="${spec##*:}"
    [ "${first}" -eq 1 ] || out+=","
    out+="{\"mount\": \"${d}\", \"fstype\": \"${t}\"}"
    first=0
  done
  printf '%s]}' "${out}"
}

run() { # run <case-log> <extra -e args...>
  local log="$1"; shift
  ANSIBLE_ROLES_PATH="${PROV}/roles" "${PLAYBOOK}" "${TMP}/scratch.yaml" \
    -e "storage_data_root=${DATA}" -e "nginx_confdir=${NGINXDIR}" \
    -e "preflight_skip_php=true" "$@" \
    > "${TMP}/${log}" 2>&1
}

# ---- 1. one ext4 volume, no storage_path -> adopted -------------------------
rm -rf "${DATA}"; mkdir -p "${DATA}/vol1"
run c1.log -e "$(mounts "${DATA}/vol1:ext4")"
check "one ext4 volume: play succeeds"        bash -c "! grep -q 'failed=1' '${TMP}/c1.log'"
check "one ext4 volume: adopted"              grep -qF "RESOLVED storage_root=[${DATA}/vol1]" "${TMP}/c1.log"
check "inspector_root derived"                grep -qF "inspector_root=[${DATA}/vol1/ddp-inspector]" "${TMP}/c1.log"

# ---- 2. ext4 volume + fuse.rclone mount -> volume adopted, fuse ignored -----
rm -rf "${DATA}"; mkdir -p "${DATA}/vol1" "${DATA}/rdbylink"
run c2.log -e "$(mounts "${DATA}/vol1:ext4" "${DATA}/rdbylink:fuse.rclone")"
check "ext4+fuse: play succeeds"              bash -c "! grep -q 'failed=1' '${TMP}/c2.log'"
check "ext4+fuse: block volume adopted"       grep -qF "RESOLVED storage_root=[${DATA}/vol1]" "${TMP}/c2.log"

# ---- 3. two ext4 volumes -> loud ambiguity failure --------------------------
rm -rf "${DATA}"; mkdir -p "${DATA}/vol1" "${DATA}/vol2"
run c3.log -e "$(mounts "${DATA}/vol1:ext4" "${DATA}/vol2:ext4")"
check "two volumes: play fails"               grep -q 'failed=1' "${TMP}/c3.log"
check "two volumes: ambiguity named"          grep -qi 'set storage_path explicitly' "${TMP}/c3.log"

# ---- 4. xfs volume qualifies (block-device allowlist) ------------------------
rm -rf "${DATA}"; mkdir -p "${DATA}/vol1"
run c4.log -e "$(mounts "${DATA}/vol1:xfs")"
check "xfs volume: adopted"                   grep -qF "RESOLVED storage_root=[${DATA}/vol1]" "${TMP}/c4.log"

# ---- 5. ONLY a fuse mount -> treated as no volume -> loud failure ------------
rm -rf "${DATA}"; mkdir -p "${DATA}/rdbylink"
run c5.log -e "$(mounts "${DATA}/rdbylink:fuse.rclone")"
check "fuse only: play fails"                 grep -q 'failed=1' "${TMP}/c5.log"
check "fuse only: create-a-volume guidance"   grep -qi 'create a small volume' "${TMP}/c5.log"

# ---- 6. no volume at all -> loud failure with create-a-volume fail_msg ------
rm -rf "${DATA}"; mkdir -p "${DATA}"
run c6.log -e '{"storage_mounts_source": []}'
check "no volume: play fails"                 grep -q 'failed=1' "${TMP}/c6.log"
check "no volume: create-a-volume guidance"   grep -qi 'create a small volume' "${TMP}/c6.log"

# ---- 7. explicit storage_path wins over detection ---------------------------
rm -rf "${DATA}"; mkdir -p "${DATA}/vol1" "${TMP}/explicit"
run c7.log -e "$(mounts "${DATA}/vol1:ext4")" -e "storage_path=${TMP}/explicit"
check "explicit path: respected verbatim"     grep -qF "RESOLVED storage_root=[${TMP}/explicit]" "${TMP}/c7.log"

# ---- 8. unedited placeholder counts as unset -> detection runs --------------
rm -rf "${DATA}"; mkdir -p "${DATA}/vol1"
run c8.log -e "$(mounts "${DATA}/vol1:ext4")" \
  -e 'storage_path=/home/<username>/data/<volume-name>'
check "placeholder: detection supersedes"     grep -qF "RESOLVED storage_root=[${DATA}/vol1]" "${TMP}/c8.log"

# ---- 9. symlinked entry: ~/data/<vol> -> shared mount elsewhere --------------
rm -rf "${DATA}"; mkdir -p "${DATA}" "${TMP}/shared/vol1"
ln -s "${TMP}/shared/vol1" "${DATA}/vol1"
run c9.log -e "$(mounts "${TMP}/shared/vol1:ext4")"
check "symlinked volume: adopted via link"    grep -qF "RESOLVED storage_root=[${DATA}/vol1]" "${TMP}/c9.log"

# ---- 10. the data dir ITSELF is a symlink to a shared mount root -------------
rm -rf "${DATA}"; mkdir -p "${TMP}/sharedroot/vol1"
ln -s "${TMP}/sharedroot" "${DATA}"
run c10.log -e "$(mounts "${TMP}/sharedroot/vol1:ext4")"
check "symlinked data root: volume adopted"   grep -qF "RESOLVED storage_root=[${TMP}/sharedroot/vol1]" "${TMP}/c10.log"

# ---- 11. missing SRC-Nginx conf dir -> loud failure --------------------------
rm -rf "${DATA}"; mkdir -p "${DATA}/vol1"
ANSIBLE_ROLES_PATH="${PROV}/roles" "${PLAYBOOK}" "${TMP}/scratch.yaml" \
  -e "storage_data_root=${DATA}" -e "nginx_confdir=${TMP}/no-such-dir" \
  -e "preflight_skip_php=true" -e "$(mounts "${DATA}/vol1:ext4")" \
  > "${TMP}/c11.log" 2>&1
check "missing nginx dir: play fails"         grep -q 'failed=1' "${TMP}/c11.log"
check "missing nginx dir: names SRC-Nginx"    grep -qi 'SRC-Nginx' "${TMP}/c11.log"

echo; [ "${FAIL}" -eq 0 ] && echo "ALL PASS" || { echo "${FAIL} FAILURES"; exit 1; }
```

`provisioning/roles/preflight/tasks/main.yaml` (full replacement):

```yaml
---
# Fail fast, operator-facing, before any apt churn. Provisioning is entirely
# operator territory (spec §2): with no study parameters, nothing a
# researcher does can make this play fail — technical fail_msgs are correct
# here. Researcher-facing errors live in the refresh script's status file.

# --- Environment asserts ----------------------------------------------------

- name: Check the SRC-Nginx app-location conf dir exists
  ansible.builtin.stat:
    path: "{{ nginx_confdir | default('/etc/nginx/app-location-conf.d') }}"
  register: preflight_nginx_dir

- name: Fail clearly when SRC-Nginx has not run on this workspace
  ansible.builtin.assert:
    that:
      - preflight_nginx_dir.stat.exists
      - preflight_nginx_dir.stat.isdir | default(false)
    fail_msg: >-
      {{ nginx_confdir | default('/etc/nginx/app-location-conf.d') }} is
      missing — the SRC-Nginx component ("Web Apps via Nginx") has not run on
      this workspace. Add SRC-Nginx to the catalog item BEFORE ddp-inspector
      (order: SRC-OS, SRC-CO, SRC-External plugin, SRC-Nginx, ddp-inspector)
      and relaunch.

- name: Check php availability (version floor 8.1; Ubuntu 24.04 ships 8.3)
  ansible.builtin.command: apt-cache policy php-fpm
  register: preflight_php_policy
  changed_when: false
  when: not (preflight_skip_php | default(false) | bool)

- name: Fail clearly when php-fpm is not installable
  ansible.builtin.assert:
    that:
      - "'Candidate:' in preflight_php_policy.stdout"
      - "'Candidate: (none)' not in preflight_php_policy.stdout"
    fail_msg: >-
      php-fpm is not installable from apt on this image. The ddp-inspector
      component targets stock Ubuntu 24.04 (PHP 8.3); check the OS image the
      item uses.
  when: not (preflight_skip_php | default(false) | bool)

# --- Storage volume resolution -----------------------------------------------
# Ported from researchcloud-ddp-transcribe preflight, with one addition: only
# BLOCK-DEVICE filesystems (ext4/xfs) qualify as storage volumes. fuse.*
# mounts — e.g. the Research-Drive-by-Link rclone mount under /data — must
# never be adopted as the durable tier. SRC passes parameters as extra-vars,
# which set_fact cannot override, so the raw storage_path INPUT is resolved
# into the storage_root FACT every consumer uses. An unedited portal
# placeholder (contains '<') counts as unset. storage_mounts_source /
# storage_data_root / nginx_confdir are testability seams.

- name: Resolve the data root default (home of the launching user)
  ansible.builtin.set_fact:
    preflight_data_root: >-
      {{ storage_data_root
         | default((ansible_env.SUDO_USER is defined and ansible_env.SUDO_USER | length > 0)
                   | ternary('/home/' ~ ansible_env.SUDO_USER | default('') ~ '/data',
                             ansible_env.HOME | default('/root') ~ '/data')) }}

- name: Record qualifying mounted filesystem targets (block-device only)
  ansible.builtin.set_fact:
    storage_mount_targets: >-
      {{ (storage_mounts_source | default(ansible_mounts))
         | selectattr('fstype', 'in', ['ext4', 'xfs'])
         | map(attribute='mount') | list }}
    storage_candidates: []
  when: >-
    (storage_path | default('') | length == 0)
    or ('<' in storage_path | default(''))

- name: Inspect the data dir itself (it may be a symlink to a shared mount root)
  ansible.builtin.stat:
    path: "{{ preflight_data_root }}"
    follow: false
  register: storage_data_root_stat
  when: storage_mount_targets is defined

- name: Resolve the real data root (follow a symlinked ~/data)
  ansible.builtin.set_fact:
    storage_data_root_real: >-
      {{ storage_data_root_stat.stat.lnk_source
         if (storage_data_root_stat.stat.islnk | default(false))
         else preflight_data_root }}
  when: storage_mount_targets is defined

- name: List entries under the data dir (volumes may be symlinks to a shared mount)
  ansible.builtin.find:
    paths: "{{ storage_data_root_real }}"
    file_type: any
    recurse: false
  register: storage_data_entries
  when: storage_mount_targets is defined

- name: Inspect data-dir entries (symlink targets vs the mount table)
  ansible.builtin.stat:
    path: "{{ item.path }}"
    follow: false
  loop: "{{ storage_data_entries.files | default([]) }}"
  loop_control:
    label: "{{ item.path }}"
  register: storage_entry_stats
  when: storage_mount_targets is defined

- name: Detect attached storage volumes (entry or its symlink target is a qualifying mount)
  ansible.builtin.set_fact:
    storage_candidates: "{{ storage_candidates + [item.stat.path] }}"
  loop: "{{ storage_entry_stats.results | default([]) }}"
  loop_control:
    label: "{{ item.stat.path | default('(skipped)') }}"
  when:
    - storage_mount_targets is defined
```

```bash
# Generated by the ddp-inspector component — do not edit.
# Source-mode-dispatching refresh: reads the study config the app's setup
# wizard wrote onto the volume, pulls donations (and transcript shards, yoda
# mode) into the local tree, and reports progress through refresh-status.json
# in RESEARCHER-FACING plain language (spec §2/§6) — this file's messages are
# rendered directly in the web UI. Serialized by flock; safe to re-run.
set -uo pipefail

ROOT="{{ inspector_root }}"
GOCMD="{{ gocmd_bin | default('/usr/local/bin/gocmd') }}"
RCLONE="{{ rclone_bin | default('/usr/local/bin/rclone') }}"
INSTANCE="${ROOT}/config/instance.json"
SOURCE="${ROOT}/config/source.json"
STATE="${ROOT}/state"
FLAG="${STATE}/refresh-requested"
STATUS="${STATE}/refresh-status.json"
LOG="${STATE}/refresh.log"
INBOX="${ROOT}/data/inbox"
TRANSCRIPTS="${ROOT}/data/analyses/transcripts"
CACHE="${ROOT}/cache"

# Not configured yet (wizard not completed): quietly nothing to do.
[ -f "${INSTANCE}" ] || exit 0

# Flag present = requested run (button or fresh config). No flag = timer
# tick: run only when the researcher chose a daily schedule.
REQUESTED=0
[ -e "${FLAG}" ] && REQUESTED=1
CADENCE="$(jq -r '.cadence // "off"' "${INSTANCE}")"
if [ "${REQUESTED}" -eq 0 ] && [ "${CADENCE}" != "daily" ]; then exit 0; fi

exec 9> "${STATE}/.refresh.lock"
flock 9
rm -f "${FLAG}"
: > "${LOG}"
exec >> "${LOG}" 2>&1

STARTED="$(date -u +%FT%TZ)"
write_status() { # write_status <phase> <finished|-> <donations|-> <message>
  local phase="$1" finished="$2" donations="$3" message="$4" tmp
  tmp="$(mktemp "${STATE}/.status.XXXXXX")"
  jq -n --arg phase "${phase}" --arg started "${STARTED}" \
        --arg finished "${finished}" --arg donations "${donations}" \
        --arg message "${message}" \
        '{phase: $phase, started_at: $started,
          finished_at: (if $finished == "-" then null else $finished end),
          donations: (if $donations == "-" then null else ($donations | tonumber) end),
          message: $message}' > "${tmp}"
  mv "${tmp}" "${STATUS}"
}
die() { # die <researcher-facing message>
  echo "[refresh] ERROR: $1"
  write_status error "$(date -u +%FT%TZ)" - "$1"
  exit 1
}
count_donations() { find -L "${INBOX}" -maxdepth 1 -name '*.json' 2>/dev/null | wc -l | tr -d ' '; }

    HOST="$(jq -r '.host' "${SOURCE}")"
    ZONE="$(jq -r '.zone' "${SOURCE}")"

    GDIR="$(mktemp -d)"; trap 'rm -rf "${GDIR}"' EXIT

{
  "irods_host": "${HOST}",
  "irods_port": 1247,
  "irods_zone_name": "${ZONE}",
  "irods_client_zone_name": "${ZONE}",
  "irods_user_name": "anonymous",
  "irods_client_user_name": "anonymous",
  "irods_authentication_scheme": "native",
  "irods_default_hash_scheme": "SHA256",
  "irods_client_server_policy": "CS_NEG_REQUIRE",
  "irods_client_server_negotiation": "request_server_negotiation",
  "irods_ssl_verify_server": "hostname"
}
EOF
    write_status probing - - "Checking the connection to the data store…"
    "${GOCMD}" ls -c "${GDIR}" -T "${TICKET}" "i:${COLLECTION}" >/dev/null \
      || die "Could not reach the donation data. The access code may have expired or been revoked — ask your data manager for a new one, paste it in Setup, and try again."
    write_status pulling - - "Fetching donations…"
    mkdir -p "${INBOX}"
    "${GOCMD}" sync -c "${GDIR}" -T "${TICKET}" "i:${COLLECTION}/inbox" "${ROOT}/data" \
      || die "Fetching donations stopped partway. This is usually temporary — try again in a few minutes."
    # Transcripts: prefer a server-side extracted tree if it ever appears
    # (FSW-unblock optimization); otherwise pull shard tars and extract
    # locally (the required path while server-side extraction is blocked).
    if "${GOCMD}" ls -c "${GDIR}" -T "${TICKET}" "i:${COLLECTION}/transcripts" >/dev/null 2>&1; then
      write_status pulling - - "Fetching transcripts…"
      "${GOCMD}" sync -c "${GDIR}" -T "${TICKET}" "i:${COLLECTION}/transcripts" "${ROOT}/data/analyses" \
        || die "Fetching transcripts stopped partway. Try again in a few minutes."
    elif "${GOCMD}" ls -c "${GDIR}" -T "${TICKET}" "i:${COLLECTION}/transcripts-tars" >/dev/null 2>&1; then
      write_status pulling - - "Fetching transcript bundles…"
      "${GOCMD}" get -c "${GDIR}" -T "${TICKET}" -f "i:${COLLECTION}/transcripts-tars" "${CACHE}" \
        || die "Fetching transcript bundles stopped partway. Try again in a few minutes."
      write_status extracting - - "Unpacking transcripts…"
      mkdir -p "${TRANSCRIPTS}"
      for t in "${CACHE}/transcripts-tars"/shard-*.tar; do
        [ -f "${t}" ] || continue
        tar -xf "${t}" -C "${TRANSCRIPTS}" || die "Unpacking transcripts failed. Try refreshing again."
        rm -f "${t}"   # prune after successful extract (cache holds partial pulls only)
      done
    else
      echo "[refresh] no transcripts on the data store (yet) — donations only"
    fi
    ;;
  rd-link)
    [ -f "${SOURCE}" ] || die "The data connection is not set up yet — open Setup and paste your Research Drive share link."
    URL="$(jq -r '.webdav_url' "${SOURCE}")"
    TOKEN="$(jq -r '.share_token' "${SOURCE}")"
    PASS_OBSCURED="$("${RCLONE}" obscure "$(jq -r '.password' "${SOURCE}")")"
    RFLAGS=(--webdav-url "${URL}" --webdav-vendor owncloud
            --webdav-user "${TOKEN}" --webdav-pass "${PASS_OBSCURED}")
    write_status probing - - "Checking the connection to Research Drive…"
    "${RCLONE}" lsd :webdav: "${RFLAGS[@]}" >/dev/null \
      || die "Could not open the Research Drive share link. The link may have expired or the password may be wrong — create a new share link, paste it in Setup, and try again."
    write_status pulling - - "Fetching donations…"
    mkdir -p "${INBOX}"
    "${RCLONE}" sync :webdav: "${INBOX}" "${RFLAGS[@]}" --include '*.json' \
      || die "Fetching donations stopped partway. This is usually temporary — try again in a few minutes."
    ;;
  local)
    LOCAL_PATH="$(jq -r '.local_path // ""' "${INSTANCE}")"
    [ -n "${LOCAL_PATH}" ] && [ -d "${LOCAL_PATH}" ] && [ -r "${LOCAL_PATH}" ] \
      || die "The configured folder (${LOCAL_PATH:-not set}) is missing or unreadable on this workspace — an operator needs to check the Setup 'folder on this workspace' path."
    if [ ! -L "${INBOX}" ]; then
      rm -rf "${INBOX}"
      ln -s "${LOCAL_PATH}" "${INBOX}"
    fi
    ;;
  *)
    die "The study setup looks incomplete — open Setup and finish the 'Where are your donations stored?' step."
    ;;
esac

N="$(count_donations)"
write_status done "$(date -u +%FT%TZ)" "${N}" "Found ${N} donation(s)."
echo "[refresh] done: ${N} donation(s)"
```

```bash
# Tier 2 verification: run the playbook twice inside a clean ubuntu:24.04
# container. Run 2 must report changed=0 (idempotency).

#   - No SRC-Nginx: we pre-create /etc/nginx/app-location-conf.d so preflight
#     passes; the nginx validate/reload handler is a no-op (no nginx binary →
#     handler task guarded below never fires because the conf render notifies

#   - No systemd: unit enable/start tasks are gated on

#   - The "volume" is a plain dir injected via storage_path (extra-var wins
#     over auto-detect by design).

REPO_DIR="$(cd "$(dirname "$0")/../.." && pwd)"

docker run --rm --cpus="$CPUS" -v "$REPO_DIR":/component:ro ubuntu:24.04 bash -c "
set -euo pipefail
export DEBIAN_FRONTEND=noninteractive
apt-get update -q && apt-get install -yq python3-pip python3-venv sudo git curl unzip >/dev/null
python3 -m venv /opt/ansible
/opt/ansible/bin/pip install -q 'ansible==9.1.0'
mkdir -p /etc/nginx/app-location-conf.d
mkdir -p /data/vol1

run_playbook() {
  /opt/ansible/bin/ansible-playbook /component/provisioning/deploy-ddp-inspector.yaml \
    -e storage_path=/data/vol1
}

echo '=== TIER 2 RUN 1 (cold) ==='
run_playbook | tee /tmp/run1.log
echo '=== TIER 2 RUN 2 (idempotency) ==='
run_playbook | tee /tmp/run2.log

recap=\$(grep -A2 'PLAY RECAP' /tmp/run2.log | tail -1)
echo \"run 2 recap: \$recap\"
changed=\$(echo \"\$recap\" | sed -n 's/.*changed=\\([0-9]*\\).*/\\1/p')
if [[ \"\$changed\" -eq 0 ]]; then
  echo 'TIER 2 PASS (run-2 changed=0)'
else
  echo \"TIER 2 FAIL (run-2 changed=\$changed — non-idempotent tasks present)\"
  exit 1
fi
"
```

```markdown
## 4. Yoda read tickets (the "access code")

Minted by the data manager on a machine with an authenticated gocmd
(e.g. the pipeline workspace or an operator laptop after `gocmd init`):

    gocmd mkticket -t read /nluu10p/home/<collection>     # mint
    gocmd modticket <ticket> --expiry 2026-09-01          # MANDATORY on real hand-offs
    gocmd lsticket                                        # audit
    gocmd rmticket <ticket>                               # revoke

Defaults are permissive (unlimited uses, NO expiry) — never hand off a
ticket without `modticket` an expiry. Hand the researcher ONLY the ticket
string + collection path; they paste both into the app's Setup. Rotation =
mint new, paste new, `rmticket` old. The workspace never holds a Yoda
account, DAP, or CO membership (anonymous ticket access, verified
2026-07-13).

## 5. Research Drive share links

Researcher-self-serve in the RD web portal: share the donations folder by
link, READ-ONLY, with a password. The app's Setup asks for the link and
password and syncs via WebDAV — no CO secrets, no provision-time wiring.
Rotation = create a new link, paste it in Setup.
```
