# Example dataset (synthetic)

A fully synthetic TikTok DDP dataset for trying out DDP Inspector without real
donations. No rows, comments, video ids, or participant ids come from real
data; everything is generated by `generate.py` (seeded, reproducible).

## Run the inspector against it

```bash
DDP_INSPECTOR_CONFIG=examples/config.examples.php ./run-dev.sh
```

Then open http://127.0.0.1:8110.

## What's in it

- `ddp/` — three participant files in the real donation naming scheme
  (`assignment=…_participant=…-tiktok.json`), each a JSON list of the five
  DDP sections with faithful row shapes and date formats:
  - a heavy user (~3.8k rows, Jan–Jul 2026),
  - a light user (~500 rows, Apr–Jul 2026),
  - an edge-case participant: empty favorites section, nonzero
    `deleted row count`, one unparseable date, an `@user/video`-style link,
    and one non-video link.
- `transcripts/` — sharded transcript tree (`<last-2-digits>/<id>.txt|.json`)
  for five of the heavy user's watched videos, covering: txt+json, txt-only,
  json-only, a low-confidence segment, and a pre-Epic-1 artifact without
  `raw_signals`. All other videos render as "Not transcribed yet."

Video ids overlap across sections and participants, so the unique-video count
is visibly lower than total rows.

## Regenerate

```bash
python3 examples/generate.py
```
